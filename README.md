# 地球守護隊：綠能接接樂

免安裝、無後端、無註冊的 HTML5 Canvas 親子遊戲。直接開啟 `index.html` 即可遊玩，也可將整個資料夾放到任一靜態網站空間。圖片、配樂與繁體中文圓體字型均已內建，可離線運作。

## 本機預覽

使用 Python：`python -m http.server 4173`，然後開啟 `http://localhost:4173`。雙擊 `index.html` 也能遊玩。

## 遊戲規則

- 電腦版橫式 16:9 遊戲，首頁為滿版教學布局，下方有「開始遊戲」按鈕。
- 首頁列出 9 種低碳寶物、9 種高污染物及魔王題介紹，讓小朋友先辨識；首頁與遊戲掉落卡片均直接使用《綠能接接樂2.jpg》擷取圖，保留原圖片下方的中文名稱。
- 有效遊玩時間 60 秒，綠能 +10、污染 −10，分數可為負值。
- 掉落道具保留橫向安全間距與各自下落路徑，限制旋轉幅度，確保降落過程不重疊；暫無空間時稍後再生成。
- 經過 20、40 秒各暫停進入一題魔王是非題，從三題抽取不重複兩題。
- 出題前 3 秒（第 17–20、37–40 秒）顯示金色邊框、閃電圖示、3／2／1 預告與提示音；預告期間仍可遊玩，暫停時預告也暫停。
- 每題 5 秒作答，答對 +20、答錯或逾時 −20；回饋與解說持續顯示，玩家點選任意畫面立即恢復遊戲，不再自動等待或跳過。也可聚焦「繼續挑戰」按鈕按 Enter／空白鍵繼續。
- 100 分以上取得現場兌獎提示。
- 觸控拖曳、滑鼠、方向鍵、A/D；Esc 暫停／繼續；切換分頁或視窗失焦會自動暫停。
- 背景配樂使用玩家選定的「Marimba Game Music Playful Tropical Jungle Puzzle」（Denis-Pavlov-Music，Pixabay）。MP3 隨遊戲提供，可離線播放；開始遊玩時播放，暫停、魔王題及結算時停止，繼續時接續原播放位置，新一局從頭播放。右上角音效開關同時控制配樂與提示音。
- Web Audio 產生接取、扣分與魔王提示音；原本的合成背景旋律已移除。

## 檔案

- `index.html`：全部遊戲介面、圖鑑與資源視窗。
- `style.css`、`landscape.css`、`mission.css`：響應式橫式版型、首頁魔王題教學與預告動畫。
- `art.js`：道具清單與 SVG 人物，遊戲道具圖片使用海報原圖。
- `assets/cards/`：從《綠能接接樂2.jpg》直接擷取的 18 張道具卡片（包含圖片下方名稱）與 3 張魔王主題圖。
- 三類圖片卡均為 119 × 96 像素。高污染卡重新擷取原海報各格的完整圖案與原文字，一起裁去左右空白後等比例置入與魔王卡相同的版型；不分拆、重寫或覆蓋原文字。首頁三類卡片採相同欄寬。
- `assets/player-boy.png`：直接擷取《綠能接接樂.jpg》中的小男生，透明背景，包含原本左側籃子。道具須碰到頭部（頭髮與臉的橢圓區域）才計分，碰到身體、手或籃子不計分。快速左右移動以連續取樣檢查碰撞，避免穿透道具。
- 遊戲左下角的「中途退出」可在遊玩、倒數、暫停或魔王題期間立即返回首頁，清除該局分數、道具與計時。
- `game.js`：狀態機、遊戲迴圈、碰撞與音效。
- `assets/audio/marimba-adventure.mp3`：木琴探險原音檔；來源與授權記錄見 `assets/audio/CREDITS.md`。
- `typography.css`、`assets/fonts/`：標題與按鈕使用源泉圓體 TW 粗體／特粗體，內文使用粉圓 Huninn。使用依目前文案製作的 WOFF2 精簡字集，保留 OFL 授權全文與來源說明，無須連線至 Google Fonts。圖片卡上的原文字保留海報樣式。
- 遊戲背景以 Canvas 繪製藍天、移動白雲、綠地、樹木與風機。
- `assets/poster-qr.png`：從提供海報擷取的原始 QR Code，標註為「線上再玩一次」，未假稱為科普下載連結。

ICDI 標誌以文字呈現。科普資源按鈕連至 ICDI 官網；正式上線時可替換為主辦單位指定的下載頁及官方品牌圖檔。本遊戲不蒐集個人資料；兌獎畫面供現場展示，未串接後端核銷或防重複兌獎。

可用 `node tools/test-game.cjs` 驗證遊戲流程，使用 `python tools/package.py` 重新製作遊戲 ZIP。
