# 地球守護隊：綠能接接樂

免安裝、無後端、無註冊的 HTML5 Canvas 親子遊戲。直接開啟 `index.html` 即可遊玩，也可將整個資料夾放到任一靜態網站空間。圖片、配樂與繁體中文圓體字型均已內建，可離線運作。

## 本機預覽

使用 Python：`python -m http.server 4173`，然後開啟 `http://localhost:4173`。雙擊 `index.html` 也能遊玩。

## 公開網站

1. 將程式碼上傳到 GitHub 。
2. 進入專案儲存庫 Settings → Pages，設定：
   - Source：Deploy from a branch
   - Branch：main
   - Folder：/ (root)
   - 按 Save
3. 等待部署完成，Pages 頁面會顯示遊戲網址：
   - https://<你的GitHub帳號名稱>.github.io/earth-guardians-game/

## 印刷用海報

提供 [展廳海報 PDF](print/earth-guardians-poster-60cm-300dpi.pdf)，可下載後交給印刷店。

- 單頁尺寸約 60 × 80.31 公分，完整嵌入 7087 × 9486 像素圖片，對應 300 dpi。
- 請以實際尺寸／100% 輸出，保持原長寬比；出血與裁切需求請與印刷店確認。
- QR 碼連至正式遊戲網址：https://greenbim-icdi.github.io/earth-guardians-game/ 。
- 海報為影像增強放大版本，建議先局部試印確認細字效果。

## 氣候風險教學

建築節能教學頁也提供 `video/冷氣26度_舒適又節能.mp4`，支援播放、暫停、進度拖曳與全螢幕，手機可在頁面內播放。影片不自動播放，並隨專案 ZIP 一起打包。

首頁「建築節能（進一步學習）」另開 `building-energy.html`，介紹冷氣設定 26°C、搭配電風扇與建築遮陽、隔熱等節能方法。教學涵蓋 PMV／PPD 定義、七級冷熱感受與六個影響因素，提供 PMV–PPD 關係滑桿及節能小練習。滑桿僅示範模型關係，不會將 26°C 直接換算成 PMV 或保證每個人舒適；教學頁不顯示家長與老師的來源補充資訊框。樣式與互動分別在 `building-energy.css`、`building-energy.js`，隨 ZIP 一併打包。

首頁「魔王挑戰題」區的三個主題採直向文字按鈕；建築節能、生物多樣性、氣候風險皆可另開完整教學頁。氣候風險教材依 `data/氣候風險.docx` 改寫，於 `climate-risk.html` 用豪雨、河邊小鎮與避難準備，區分危害度、暴露度、脆弱度，並提供互動卡片與一題暴露度小練習；練習不計入遊戲分數。

教學頁加入 `video/氣候風險_小熊說故事.mp4`，使用 HTML5 影片播放器，支援播放、暫停、進度拖曳及全螢幕；手機可在頁面內播放，不會自動播放聲音。播放器寬度隨裝置調整。

教學的樣式與互動分別放在 `climate-risk.css`、`climate-risk.js`；原教材圖另存為 `assets/climate-risk-diagram.png`，直接顯示於教學頁的三因子關係圖區。教學檔案、影片、字型與圖片都隨 ZIP 打包，無需後端服務。部署時請一併上傳 `video` 資料夾。

## 遊戲規則

- 首頁為滿版教學布局，下方有「開始遊戲」按鈕。
- 開始遊戲後，遊玩與結算畫面依裝置可視區域調整長寬比：手機直式滿版、平板及電腦依視窗比例展開，不再限制為橫式 16:9。
- 首頁列出 9 種低碳寶物、9 種高污染物及魔王題介紹，讓小朋友先辨識；首頁與遊戲掉落卡片均直接使用《綠能接接樂.jpg》擷取圖，保留原圖片下方的中文名稱。
- 有效遊玩時間 60 秒，綠能 +10、污染 −10，分數可為負值。
- 掉落順序固定為「3 個低碳道具 → 1 個高污染道具」，循環生成；各類道具的圖案仍隨機選取。只有成功生成道具才推進順序，暫停、魔王題與調整畫面尺寸不重置順序，重新開始或中途退出才重置。
- 掉落道具保留橫向安全間距與各自下落路徑，限制旋轉幅度，確保降落過程不重疊；暫無空間時稍後再生成。
- 經過 20、40 秒各暫停進入一題魔王挑戰題，從三題抽取不重複兩題。
- 出題前 3 秒（第 17–20、37–40 秒）顯示金色邊框、閃電圖示、3／2／1 預告與提示音；預告期間仍可遊玩，暫停時預告也暫停。
- 每題 10 秒作答，答對 +20、答錯或逾時 −20；回饋與解說持續顯示，玩家點選任意畫面立即恢復遊戲，不再自動等待或跳過。也可聚焦「繼續挑戰」按鈕按 Enter／空白鍵繼續。
- 300 分以上顯示現場送精美小禮物；未達 300 分顯示「再接再厲」。結算頁提供「回到首頁」按鈕，清除該局狀態並返回玩法介紹；玩家需再按首頁的「開始遊戲」才會開始新一局。
- 觸控拖曳、滑鼠、方向鍵、A/D；Esc 暫停／繼續；切換分頁或視窗失焦會自動暫停。
- 背景配樂使用玩家選定的「Marimba Game Music Playful Tropical Jungle Puzzle」（Denis-Pavlov-Music，Pixabay）。MP3 隨遊戲提供，可離線播放；開始遊玩時播放，暫停、魔王題及結算時停止，繼續時接續原播放位置，新一局從頭播放。右上角音效開關同時控制配樂與提示音。
- Web Audio 產生接取、扣分與魔王提示音；原本的合成背景旋律已移除。

## 依裝置調整遊戲畫面長寬比

這項功能由 `responsive.css` 與 `game.js` 配合實作，同時調整介面布局及 Canvas 遊戲座標，避免只拉伸畫布造成角色、卡片變形或觸控位置偏移。

### 畫面布局：`responsive.css`

- 網頁文字最小字級為 17px，標題另行放大；首頁可捲動閱讀，避免大字被固定高度裁切。卡片圖片中原有的文字隨圖片等比例顯示，不受 CSS 字級控制。
- 遊戲開始後，`body` 會移除 `at-home` 類別，透過 `body:not(.at-home)` 將遊戲容器固定在可視區域，設定寬高為 `100%`、`aspect-ratio: auto`，解除原本的固定長寬比。
- `100dvh` 對應瀏覽器目前的可視高度，配合 `env(safe-area-inset-*)` 為瀏海與底部手勢區保留操作空間。這是網頁內滿版，不會強制啟動瀏覽器的全螢幕模式。
- 手機寬度不超過 600px 時，調整積分板、按鈕、魔王題及文字大小。結算畫面採直向排列；高度不超過 600px 的橫式畫面改用雙欄排列，內容過高時可捲動查看。
- `index.html` 將 `responsive.css` 放在其他樣式之後載入，讓自適應規則能覆蓋原有橫式布局。

### 遊戲座標：`game.js`

`resize()` 讀取 Canvas 的實際顯示尺寸，以 `aspect = 顯示寬度 / 顯示高度` 計算遊戲世界大小：

```js
const nextW = 720 * Math.max(1, aspect);
const nextH = 720 / Math.min(1, aspect);
```

橫式畫面維持遊戲世界高度 720，向左右延伸；直式畫面維持寬度 720，向上下延伸。因此人物、道具卡與角色碰撞區能沿用原有尺寸，維持比例。Canvas 的實際像素另依 `devicePixelRatio`（上限 2）設定，再由 `ctx.setTransform()` 對應遊戲座標與顯示尺寸，兼顧清晰度及裝置負載。

- **觸控與滑鼠**：`position()` 將螢幕上的水平位置換算為目前遊戲世界的 `W` 座標，並限制角色不超出左右邊界。
- **掉落速度**：`fallScale()` 依世界高度調整下落速度與加速度，讓直式畫面增加落下距離後，仍保持接近原本的反應時間。
- **道具不重疊**：`spawnItem()` 依目前的 `W` 計算可用通道數，保留通道間距與安全距離；窄螢幕會減少同時可用的通道。
- **旋轉螢幕或調整視窗**：透過 `window.resize` 與 `ResizeObserver` 重新計算尺寸。世界大小改變時，依比例調整角色與落葉位置，清空當下掉落物、浮分與粒子，再短暫等待後生成新道具；分數、遊戲進度及魔王題作答狀態保留。

### 驗證方式

執行 `node tools/test-game.cjs`，會模擬 390 × 844、360 × 640、844 × 390、768 × 1024、1366 × 768 五種尺寸的完整遊戲，檢查長寬比、觸控邊界、全身碰撞、道具不重疊與遊玩中旋轉螢幕後的狀態。

- 三類圖片卡均為 119 × 96 像素。高污染卡重新擷取原海報各格的完整圖案與原文字，一起裁去左右空白後等比例置入與魔王卡相同的版型；不分拆、重寫或覆蓋原文字。首頁三類卡片採相同欄寬。

- 遊戲左下角的「中途退出」可在遊玩、倒數、暫停或魔王題期間立即返回首頁，清除該局分數、道具與計時。

- `assets/audio/marimba-adventure.mp3`：木琴探險原音檔；來源與授權記錄見 `assets/audio/CREDITS.md`。
- `typography.css`、`assets/fonts/`：標題與按鈕使用源泉圓體 TW 粗體／特粗體，內文使用粉圓 Huninn。使用依目前文案製作的 WOFF2 精簡字集，保留 OFL 授權全文與來源說明，無須連線至 Google Fonts。圖片卡上的原文字保留海報樣式。

## 自動檢查網站更新

`cache-refresh.js` 會在開啟頁面、切回分頁及每 60 秒，以 `cache: no-store` 檢查 `site-version.json`。發現不同版本時，以新網址重新載入；遊戲進行、暫停、魔王題或結算中會等回到首頁才更新，影片播放中也會延後更新。離線或檢查失敗不影響使用，並有重新載入次數保護，避免部署未同步時不斷重整。

此功能處理的是瀏覽器快取，不清除 Cookie，也不能刪除整個瀏覽器或其他網站的快取。`tools/version-assets.py` 依網站內容產生版本，替 HTML、程式、樣式、字型、圖片與影片網址加上版本參數；動態遊戲圖片透過 `SiteVersion.url()` 使用相同版本。

每次修改完成、上傳 GitHub 前，執行 `python tools/package.py`，會自動更新版本並打包。請把產生的 `site-version.json`、`cache-refresh.js` 及所有變更一起提交上傳。也可只執行 `python tools/version-assets.py` 更新版本。GitHub Pages 仍須完成部署；首次導入此功能時，原本已停留在不含檢查程式的舊頁面，可能需要手動重新整理一次。

檢查：`node tools/test-cache-refresh.cjs`。
